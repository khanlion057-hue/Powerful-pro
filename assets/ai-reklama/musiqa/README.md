# AI-reklama — qo'shimcha kuylar (ixtiyoriy)

Sukut bo'yicha Reels videosi uchun kuy **brauzerda yaratiladi** (3 kayfiyat: Energik, Yumshoq, Premium) — fayl kerak emas,
mualliflik huquqi muammosi yo'q.

O'zingizning litsenziyali treklaringizni qo'shmoqchi bo'lsangiz:

1. `.mp3` / `.m4a` / `.ogg` faylni shu papkaga qo'ying (nomi: lotin harf, raqam, `-` `_` `.`; masalan `energik-1.mp3`).
2. Shu papkaga **`LICENSE.txt`** qo'ying — treklar qayerdan olingani va ulardan reklamada foydalanish huquqi yozilsin.
3. Deploy qiling. Build `manifest.json` ni o'zi yaratadi — treklar «Format va musiqa» qadamida ro'yxatga chiqadi.

`LICENSE.txt` bo'lmasa — treklar saytga chiqmaydi (build ularni olib tashlaydi). Eng ko'pi 20 ta trek; video 20 MB dan oshmasin.
